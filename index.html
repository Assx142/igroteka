📖 Руководство оператора

1. Вход в систему

Для входа в админ-панель используйте данные администратора:

  • Email: admin@igroteka.ru
  • Пароль: admin

2. Управление товарами

Добавление товара:

  1. Войдите как администратор
  2. Перейдите в раздел "Админ" → "Товары"
  3. Заполните форму добавления товара
  4. Нажмите "Добавить"

Редактирование товара: Нажмите кнопку "Ред." рядом с товаром

Удаление товара: Нажмите кнопку "Уд." и подтвердите действие

3. Управление заказами

  1. Перейдите в раздел "Админ" → "Заказы"
  2. Выберите заказ из списка
  3. Измените статус заказа через выпадающий список
  4. Статусы: В обработке → Подтверждён → Отправлен → Доставлен

4. Типовые ситуации

Товар закончился: Уменьшите остаток до 0 или удалите товар

Заказ завис: Проверьте статус и обновите его

Ошибка в данных: Отредактируйте товар или заказ через админ-панель
